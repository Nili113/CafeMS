# CafeMS

## Setup

```bash
git clone https://github.com/Nili113/CafeMS.git
cd CafeMS
npm install
npm run dev
```

App runs at `http://localhost:5173`.

## Portals & Credentials

All portals require authentication before entry.

### 1. Super Admin Platform
- URL: `http://localhost:5173/admin`
- Email: `admin@cafems.io`
- Password: `password123`

### 2. Cafe Client Operations (Cafe XYZ)
- URL: `http://localhost:5173/client`
- Email: `manager@cafexyz.com`
- Password: `password123`

### 3. Contactless Customer Dining
- URL: `http://localhost:5173/table/4`
- Direct table QR landing (no login required for dining guests).
